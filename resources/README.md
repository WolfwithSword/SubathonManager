# Shared Resources

Files located here will be useable as resources from *any* widget hosted from subathonmanager.

Technically, anything can access them at subathonmanager's url :)

```
http://localhost:<port>/resources/<path>/<to>/<file>
http://localhost:<port>/resources/images/logos/logo.png

```

or inside widgets

```html
<img src="/resources/images/logos/logo.png">
<audio src="/resources/audio/alert.mp3"></audio>
```
